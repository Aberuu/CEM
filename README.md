## Teknologi
- **HTML5 & CSS3 murni** (tanpa JavaScript, tanpa framework, tanpa backend)
- Google Fonts: `Playfair Display`, `Archivo`, `Manrope`
- Ikon SVG inline
- Trik CSS: menu hamburger (`:checked`), filter kategori (`:has()`), pengalih bahasa BA/EN (`:has()`), animasi muat dan scroll (`@keyframes` + `animation-timeline: view()`)

## Struktur Halaman
- `index.html` — Beranda, hero, 3 event unggulan, dan ajakan kalender
- `events.html` — Daftar lengkap event dan filter kategori
- `calendar.html` — Tabel kalender bulanan dengan tanggal event
- `about.html` — Profil kelompok, ID LinkedIn, kontak, dan peta kampus
- `event-seminar-ai.html`, `event-hackathon-kampus.html`, `event-pentas-seni.html` — Detail event, rundown, pendaftaran, `.ics`, dan berbagi WhatsApp
